# Bid Radar Setup

Leia o README.md, o SKILL.md e o docs/ESTRUTURA.md deste pacote. Vamos criar o projeto 'Radar de Licitações', uma plataforma web privada single-tenant (um único perfil 'Operador') sobre Supabase, seguindo o caminho de build Lovable + Supabase descrito na ESTRUTURA. Crie o projeto React + Tailwind + shadcn/ui e conecte ao meu projeto Supabase. Ainda NÃO crie páginas nem tabelas — apenas configure a estrutura base e confirme a conexão com o Supabase funcionando.

This project was built with [Lovable](https://lovable.dev).
